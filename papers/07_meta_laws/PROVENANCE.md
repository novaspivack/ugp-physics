## 3. ML-7 — Zipf corpus validation

Empirical Zipf validation is **only** part of this monograph (no separate Zipf paper). Canonical outputs for ML-7 are the batch CSV and montage produced by the script below (or a frozen copy checked in next to this paper).

| Artifact | Role |
|----------|------|
| `UGP_theory_cross_domain_proofs.py` | Single script: downloads Gutenberg texts (optional), analyzes each corpus, writes `batch_zipf_summary.csv`, per-corpus PNGs, and `global_rank_surprisal_montage.png` when `EXPORT_LATEX` and montage path run. |
| `zipf_outputs/books/` | Cached UTF-8 `.txt` files downloaded from Project Gutenberg URLs listed in the script. |
| `zipf_outputs/*_rankfreq.csv` | Per-corpus rank–frequency exports. |

**Script identity:** header records `VERSION_TAG = "UGP Zipf tester v2-weighted+verdict"`. Record this string plus `git rev-parse HEAD` when freezing.

**Non-confirmations in the frozen batch:** `newton_principia.txt`, `roget_thesaurus.txt` (see CSV `verdict` column).
