Direct = standard Wolfram 1‑D binary CA (radius‑1). UWCA Emulation = the same CA computed via local minterm rails and OR‑accumulation. UWCA‑Arith = a residue‑wise mod‑p local gadget demo (using primes p∈{3,5,17,19,257}); neighbours provide (L,C) rails, passes perform add/sub/compare per‑prime, then commit. View toggles: choose prime focus, zero=black, binarize residues, and Δ overlay to highlight per‑step changes.

What are these modes showing?

Direct CA (lookup)

Classic Wolfram 1‑D binary cellular automata. Each new cell depends on its left/center/right neighbours via an 8‑bit rule #. One pass computes the next row.

UWCA Emulation (minterms)

Same CA, but realised as a local, multi‑pass micro‑rule: (1) **distribute** neighbour rails (L/C/R), (2) compute the **minterm** rails that match the rule’s 1‑patterns, (3) **OR‑reduce** minterms into NEXT, then **commit** the next row. This shows how a local circuit/schedule can implement global CA behaviour (universality witness via Rule‑110).

UWCA‑Arith (mod‑p gadgets)

A toy version of the arithmetic UWCA layer. Each site carries residues for primes p∈{3,5,17,19,257}. Neighbour coupling is used to fetch (L,C) operands; passes perform local mod‑p add/sub/cmp rails per prime, then a commit pass. It mirrors the building blocks (adders, comparators) used in the real UGP/UWCA substrate.

Viewing options (arith mode)

Prime view: show All primes stacked, Cycle through primes each generation, or focus a single prime rail (p=3,5,17,19,257).

Zero=black: render residue 0 as pure black (useful for sparse, structured patterns).

Binarize: threshold residues to {0,1} by mapping non‑zero→1 — makes wavefronts and arithmetic cones crisp.

Δ overlay: highlight sites whose shown residue changed this step; unchanged sites are dimmed. Works for both binary CA and arith mode.

Switch the Render control to Time to see passes sweep horizontally; in Space each row is a generation.
