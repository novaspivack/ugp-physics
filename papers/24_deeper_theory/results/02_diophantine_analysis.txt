THE JOINT CONSTRAINT AS A DIOPHANTINE SYSTEM
--------------------------------------------------

Variables: n (ridge level), b2 (divisor of R_n)

Equations:
  (1) R_n = 2^n - 16                          [ridge definition]
  (2) b2 * q2 = R_n,  b2, q2 > 15             [divisor pair]
  (3) b1 = b2 + q2 + 7 = b2 + R_n/b2 + 7     [mirror sum]
  (4) c1 = b1*(b2 - 13) + 20  is prime        [prime-lock]
  (5) delta_UGP(b1) = C/b1 = delta_target     [physical viability]

Eliminating q2 using (2) and (3):
  b1 = b2 + R_n/b2 + 7

From (5): b1 = C/delta_target = b1_req
  b1_req = 1.21173843 / 0.01659912
         = 73.00017447

Substituting into b1 = b2 + R_n/b2 + 7:
  b2 + R_n/b2 + 7 = b1_req
  b2^2 - (b1_req - 7)*b2 + R_n = 0

This is a QUADRATIC IN b2 for each n.
