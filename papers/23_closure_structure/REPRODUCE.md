## Figures

Figures are generated by scripts in the the closure-handoff package package:

```bash

cd <handoff_root>/code
python3 ugp_internal_test.py   # → handoff/figures/ugp_internal_test.png  (Fig. 1)
python3 generation_test.py      # → handoff/figures/generation_test.png     (Fig. 2)
```

Pre-generated figures are included in `papers/24_closure_structure/`:
- `fig_ugp_internal_test.png` — main analysis panel (Fig. 1)
