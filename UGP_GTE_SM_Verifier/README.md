# GTE Verifier Monolith — v8

Single-file, deterministic verifier and report generator for the **S\[I\]-GTE Universal Calibration Law (UCL)**, with an integrated multi-sector physics engine and the full **UGP → GTE derivation stack**.

The script is self-contained and reproducible (NumPy only at minimum; matplotlib and SciPy optional). All results are deterministic at fixed canonical knobs. It emits JSON / CSV / Markdown / TeX artifacts suitable for auditing and peer review.

```bash
python3 UGP_GTE_SM_Verifier.py --help          # all flags + mode epilog
python3 UGP_GTE_SM_Verifier.py --write-help-md # writes HELP.md in this directory
```

## Verifier modes — what each demonstrates

These modes answer **different** audit questions. They are not interchangeable.

### 1. Dual-path (P01 headline, ~0.29% theoretical σ)

```bash
python3 UGP_GTE_SM_Verifier.py --n 10 --mode phys --quiet \
  --coeffs-source empirical --imt-mixer-mode v12 --run-dual-path
```

| Arm | UCL coefficients | renorm_K | URC | Typical primary σ |
|-----|------------------|----------|-----|-------------------|
| Empirical | Frozen **UCL2.3** | 1400 (canonical) | off | ~**0.003%** |
| Theoretical | Same **UCL2.3** | Bekenstein–Fisher derived | locked layer | ~**0.29%** |

**What it demonstrates:** The paper’s locked prediction uses the empirical UCL functional form at prediction time, with structural renorm and the disclosed URC correction—not a full substitution of the nine Elegant Kernel targets into the mass pipeline.

**Artifacts:** `dual_path_comparison.json`, `dual_path_comparison.md`, `theoretical_coefficients.json` (coefficient **target** table; L∞ vs empirical ≈ 0.007).

**Common misconception:** `--run-dual-path` does **not** run masses with `THEORETICAL_COEFF_VECTOR`. The coefficient comparison table inside the JSON is diagnostic only.

### 2. Bare Elegant Kernel / limit mode (~1.1% σ)

```bash
python3 UGP_GTE_SM_Verifier.py --n 10 --mode phys --quiet \
  --coeffs-source limit --imt-mixer-mode v12 --run-fully-theoretical
```

Aliases for `--coeffs-source`: `theoretical`, `elegant`.

| Component | Source |
|-----------|--------|
| UCL | `THEORETICAL_COEFF_VECTOR` (`k_gen = φ cos(π/10)`, quarter-lock rationals, …) |
| E_base mixer | `calculate_theoretical_E_base()` |

**What it demonstrates:** Whether the nine-component Elegant Kernel alone closes the charged-fermion spectrum (convergence toward the palette in P01 Appendix B). This is **not** the 0.293% headline result.

**Artifacts:** `fully_theoretical_results.json`, `fully_theoretical_grand_synthesis.md`.

### 3. IMT mixer: `v12` vs `cmca`

```bash
# Structural CMCA two-anchor mixer (082-IMT-HOLO / three-tape CMCA)
python3 UGP_GTE_SM_Verifier.py --n 10 --mode phys --quiet \
  --coeffs-source empirical --imt-mixer-mode cmca --run-dual-path
```

| Mode | Role |
|------|------|
| `v12` (default) | Embedded Phase/Binding weights; canonical primary score |
| `cmca` | CMCA L¹ holographic channel + electron/muon two-anchor closure |

In the current closure, charged-fermion masses are **numerically equivalent** between `v12` and `cmca`; the flag audits mixer dependence.

Runs the complete battery (gauge, CKM, PMNS, nulls, DOF ledger, etc.). For frozen coefficient artifacts after kernel updates, use the P01 audit driver:

## What UGP_GTE_SM_Verifier does

**Primary verdict** — tests the formal UCL proof path and the parameter-free W-boson ρ-law invariant. These are the two metrics that determine PASS/FAIL.

**Physics engine** (supplementary and auditable) — Yukawa couplings, CKM matrix (two independent paths), PMNS matrix, electroweak echoes, 1-loop RGEs, anomaly cancellation proofs, Higgs sector, neutrino forecasts, hadron echoes, information geometry.

**Anti-overfitting batteries** — permutation nulls, LOOCV ridge probe, MDL/DOF accounting, broad-flat-optimum sweeps, noise-sensitivity, coefficient-jitter robustness.

**Reproducibility** — SHA-256 digests of code, coefficient vector, and canonical triples are embedded in every report. A reference-lock / verify workflow allows exact regression-to-baseline checks.
