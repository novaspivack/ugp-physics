
## Data acquisition

The UCI Polish Companies Bankruptcy Dataset is not included in this repository.
Download it from: https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data

Place the ARFF files in `data/`:
```
information_profit/real_world_validation/data/
    1year.arff  2year.arff  3year.arff  4year.arff  5year.arff
```

Then run the validation scripts.
