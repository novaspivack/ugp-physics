# Computational concordance

This directory holds **reproducible tables and JSON reports** for the Unified
Rigidity capstone: concordance across PSC / UGP / dynamical layers, perturbation
elimination ledgers, and basin statistics for the canonical seed.

Scripts that regenerate these files should be added next to the data with clear
entry points; until then, sources are cited in each artifact’s header or
`provenance` column.

See also: [unified-rigidity-lean](https://github.com/novaspivack/unified-rigidity-lean)
(`ASSUMPTION_LEDGER.md` for Lean-side classification of the same claims).

**RSUC six-triple family:** `UgpLean.Classification.Bounds` (`Candidates` at $n{=}10$): $(a,73,c)$ for $a\in\{1,5,9\}$, $c\in\{823,2137\}$. The Lepton Seed $(1,73,823)$ is the MDL-minimal representative; $(1,73,2137)$ is mirror-related; other $a$ values are residual survivors with the same canonical representative under RSUC.
