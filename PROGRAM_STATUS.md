# Programme Status

This repository records an active research programme. It is not a finished or final theory.

The framework is currently undergoing a systematic audit, together with corrections and
improvements prompted by reader feedback. Several significant issues have been identified,
and work on them is in progress. Some claims, derivations and interpretations in the current
papers may be revised, qualified or withdrawn in future versions.

Revised versions of the papers, code and formal proofs will be released when this work is
complete. Until then, please read the current versions as work in progress. Comments and
corrections are welcome.

*Status as of October 2026.*
