### **4. Rapid Turnover: Pattern Persistence, Not Substrate**

**Key Insight:** Biology doesn't maintain the SAME atoms—it maintains the PATTERN.

**Analogy:**
- **River:** Shape persists (coherence) despite water changing (noise)
- **Cell:** Organization persists despite molecular turnover

**Turnover Rates:**

| Component | Half-Life | Strategy |
|-----------|-----------|----------|
| Small molecules (ATP, glucose) | Seconds-minutes | Rapid recycling |
| Proteins | Hours-days | Continuous synthesis/degradation |
| Lipids | Days-weeks | Membrane recycling |
| Organelles | Days-weeks | Autophagy/biogenesis |
| Cells | Days-years | Division/apoptosis |

**Why this works:**
- Errors accumulate in MOLECULES, not PATTERNS
- Replace molecules before errors propagate
- Profit accounting on PATTERN, not PARTICLES

**This is like quantum error correction:** Logical qubit (pattern) persists despite physical qubit errors (noise).

### **5. Noise-to-Signal Conversion**

**Brilliant trick:** Use some additive noise CONSTRUCTIVELY

**Mechanisms:**

#### **Stochastic Resonance**
- Weak signal + optimal noise → enhanced detection
- Example: Hair cells in inner ear

#### **Brownian Ratchets**
- Random thermal motion → directed transport
- Example: Kinesin walking on microtubules
- Converts thermal (additive) noise → useful work

#### **Channel Gating**
- Thermal fluctuations → probabilistic opening
- Example: Ion channels (10-100 ms opening)
- Randomness enables rapid response

#### **Immune Diversity**
- Random VDJ recombination → antibody variety
- "Noise" in DNA cutting → adaptive advantage

**Effect:** Converts some "external additive noise" → "internal multiplicative signal"

**This changes the effective noise type!**
- E35 showed: multiplicative noise OK (threshold 1.11)
- E35 showed: additive noise BAD (threshold 0.59)
- Biology: Convert additive → multiplicative when possible
