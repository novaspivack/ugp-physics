\begin{definition}[Encoding and Decoding]\label{def:pr0_encode_decode}

\begin{definition}[Four-Phase Microstep]\label{def:microstep}
Each macrostep (Rule~110 tick) is realized by four PR-0 substeps:
\begin{description}

\item[Compute (C)] Evaluate the exact Rule~110 truth table via

\begin{cases}
1 & (x_{i-1},x_i,x_{i+1}) \in \{001,010,011,101,110\},\\
0 & \text{otherwise,}
\end{cases}

where $x_j=\pi(U_t)_j$.
\item[Inhibit (I)] Apply soft damping: $U^{(I)} = (1-\gamma)U^{(S)} + \gamma \mu$ with $\gamma=0$ in the pass configuration.
\item[Commit (K)] Pull toward guard bands: $U_{t+1} = (1-\lambda)U^{(I)} + \lambda(\mu + (\tilde{f}-0.5)2\Delta)$ with $\lambda=1$.
\end{description}
Periodic boundaries are enforced in the sampling phase.
\end{definition}

\begin{theorem}[WTU via Soft Rule~110]\label{thm:pr0_wtu}

\begin{proof}
The guard-banded encoding ensures the sampled field never crosses the threshold except when dictated by the truth table; the commit phase writes back the exact bit amplitudes $(\mu\pm\Delta)$. Since Rule~110 depends only on three-bit neighborhoods and the same map is applied uniformly, the decoded state $\pi(U_{t+1})$ equals $X_{t+1}$ whenever $\pi(U_t)=X_t$. Induction on $t$ completes the argument. \section{Motivation and Conceptual Placement}

Transputational Universality comes in two forms:

\begin{itemize}
\item \textbf{Weak TU (WTU):} A computable substrate can emulate any admissible
      computable reflexive process on compact space--time windows with arbitrarily small error.
\item \textbf{Strong TU (STU):} A \emph{physical} substrate can generate
      real-valued, entropy-driven trajectories that are not computably enumerable,
      i.e.\ physically non-Turing dynamical flows.
\end{itemize}

WTU is the strongest notion that can be \emph{meaningfully} validated inside a discrete,
digitally simulated PR-0 run.

The Absolute Gauge program and the ΛΩ–$Z_2$ correspondence require only WTU:
they require PR-0 to be a \emph{universal discrete reflexive gauge}, not a hypercomputational
physical device.

\pi\!\big(\mathcal{U}^t(\iota(S_0^\*))\big)

up to an error $\varepsilon$ that can be made arbitrarily small.
\end{definition}

This is the classical universality notion used for:
