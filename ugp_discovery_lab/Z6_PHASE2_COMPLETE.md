## Technical Solution

### **The Key Enhancement**

**Problem**: arcsin() only returns [-90°, 90°], losing information for large phases like 195°

**Solution**: Extract full phase directly from complex matrix element:

```python
# U_e3 = s13 · exp(-i·delta)
# Therefore: delta = -arg(U_e3)
delta_from_matrix = -np.angle(mixing_matrix[0, 2])
delta_full_deg = np.degrees(delta_from_matrix) % 360
```

This gives the full range [0°, 360°), allowing correct Z₆ projection for all phases.

**Fallback**: If matrix not available, test all Z₆ values against sin(delta) from Jarlskog
